### Product Principles
1. **Lightweight and Fast**: Sub-second startup, low memory footprint (<85MB idle heap), instant file indexing, and smooth 60fps scrolling on large source files.
2. **Keyboard-First**: Comprehensive keyboard shortcuts for every action, full Sublime Text & VS Code multi-cursor editing, and universal Command Palette (`Ctrl+Shift+P`).
3. **Beautiful and Customizable**: Modern translucent aesthetics, custom themes (One Dark Pro, Catppuccin, Tokyo Night, Dracula, Material), custom font ligatures, and custom accent colors.
4. **Intelligent Coding Assistance**: Language Server Protocol (LSP) language intelligence, DAP interactive debugging, code actions, hover docs, and functional offline/multi-provider AI Assistant.
5. **Excellent Web Development Experience**: Integrated Web Development Toolkit, Live Server with auto-reload, Live HTML preview, CSS Peek, color pickers, and Emmet abbreviation engine.
6. **Secure Extension Ecosystem**: Sandboxed host isolation with 20 categories of curated extensions, manifest-driven activation, and granular permission boundaries.
7. **Reliable Across Windows, macOS and Linux**: First-class support for Windows (with automated compiler detection for Kotlin, JDK, Python, MinGW), macOS (universal binary), and Linux (AppImage, DEB).

### Definition of Done
Every feature in Xivig Text Editor satisfies:
- **Functional implementation**: End-to-end verified logic with no mocked regressions.
- **Settings and customization**: User-configurable via Settings UI or JSON preferences where appropriate.
- **Keyboard shortcuts**: Direct, conflict-free hotkey bindings for fast invocation.
- **Command palette integration**: Searchable and runnable from `Ctrl+Shift+P` / `F1`.
- **Error handling**: Resilient graceful degradation and informative user guidance.
- **Automated tests**: Robust test suites across unit, store, integration, and IPC layers.
- **Documentation**: Clear coverage across README, HOW_TO, release notes, and changelogs.
